MLOG SCANNER BRIDGE V2.7 — UM CLIQUE POR CICLO

1) Salve o ZIP MLOG_Scanner_Bridge_v27_Um_Clique_Por_Ciclo.zip em Downloads.
2) No CMD do Windows:

cd /d "%USERPROFILE%\Downloads\MLOG-Scanner-Bridge"
powershell -NoProfile -Command "Expand-Archive -LiteralPath (Join-Path $env:USERPROFILE 'Downloads\MLOG_Scanner_Bridge_v27_Um_Clique_Por_Ciclo.zip') -DestinationPath . -Force"
git add -A
git commit -m "Bridge v27 sem cliques duplicados e com novas logos"
git push origin main

3) GitHub: https://github.com/seridoplast/MLOG-Scanner-Bridge/actions
Baixe MLOG-Scanner-Bridge-v27-APK e extraia app-debug.apk para Downloads.

4) Coletores (USB, depuracao autorizada):
"%USERPROFILE%\Downloads\platform-tools\adb.exe" devices
"%USERPROFILE%\Downloads\platform-tools\adb.exe" install -r "%USERPROFILE%\Downloads\app-debug.apk"

5) Em caso de falha sem confirmacao:
Bridge > Diagnostico > Rearmar apos falha. Confira o pedido antes de rearmar.

OBS: nao havera fila de cliques ou de codigos atrasados. Novos bipes enquanto o ciclo
anterior estiver bloqueado sao ignorados. A confirmacao depende do CMX.

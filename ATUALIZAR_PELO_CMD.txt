MLOG Scanner Bridge v1.1 (ZIP do projeto)

1. SALVAR O ZIP EM DOWNLOADS
2. CMD - SUBIR PARA GITHUB:

cd /d "%USERPROFILE%\Downloads\MLOG-Scanner-Bridge"
powershell -NoProfile -Command "Expand-Archive -LiteralPath (Join-Path $env:USERPROFILE 'Downloads\MLOG_Scanner_Bridge_v11_Enter_Cada_Bipe.zip') -DestinationPath . -Force"
git add -A
git commit -m "MLOG Bridge v11 Enter por leitura"
git push origin main

3. ACTIONS: https://github.com/seridoplast/MLOG-Scanner-Bridge/actions
   Baixar o artefato MLOG-Scanner-Bridge-v11-APK; extrair app-debug.apk em Downloads.

4. INSTALAR ADB (DEPURACAO USB):

"%USERPROFILE%\Downloads\platform-tools\adb.exe" devices
"%USERPROFILE%\Downloads\platform-tools\adb.exe" install -r "%USERPROFILE%\Downloads\app-debug.apk"

Nao desinstalar o app antigo sem antes analisar erros de assinatura.

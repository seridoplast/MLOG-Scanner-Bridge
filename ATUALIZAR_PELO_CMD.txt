MLOG SCANNER BRIDGE v0.8 — ATUALIZACAO E INSTALACAO

1) Baixe MLOG_Scanner_Bridge_v8_Foco_Estavel.zip na pasta Downloads.
2) Abra CMD e execute:

cd /d "%USERPROFILE%\Downloads\MLOG-Scanner-Bridge"
powershell -NoProfile -Command "Expand-Archive -LiteralPath (Join-Path $env:USERPROFILE 'Downloads\MLOG_Scanner_Bridge_v8_Foco_Estavel.zip') -DestinationPath . -Force"
git add -A
git commit -m "MLOG Bridge v8 foco estavel"
git push origin main

3) Espere GitHub Actions ficar VERDE, baixe o artefato MLOG-Scanner-Bridge-v8-APK,
   extraia app-debug.apk na pasta Downloads.

4) Conecte o CMX por USB, deixe Depuracao USB ativa e AUTORIZE o PC:

"%USERPROFILE%\Downloads\platform-tools\adb.exe" devices
"%USERPROFILE%\Downloads\platform-tools\adb.exe" install -r "%USERPROFILE%\Downloads\app-debug.apk"

Observacao: nao altere formatos/mode output no CMX pelo Bridge; o v0.8 nao envia comandos.

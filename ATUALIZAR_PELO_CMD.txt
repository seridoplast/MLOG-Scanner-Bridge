MLOG Scanner Bridge v2.9.6 — 200 ms e barra compacta com Apagar

1. Baixar MLOG_Scanner_Bridge_v296_200ms_Teclado_Oculto_Apagar.zip para Downloads

2. Abrir CMD:
cd /d "%USERPROFILE%\Downloads\MLOG-Scanner-Bridge"
powershell -NoProfile -Command "Expand-Archive -LiteralPath (Join-Path $env:USERPROFILE 'Downloads\MLOG_Scanner_Bridge_v296_200ms_Teclado_Oculto_Apagar.zip') -DestinationPath . -Force"
git add -A
git commit -m "Bridge v296 200ms teclado compacto e apagar"
git push origin main

3. Acessar https://github.com/seridoplast/MLOG-Scanner-Bridge/actions
   Baixar MLOG-Scanner-Bridge-v296-APK depois que a compilacao ficar verde.

4. Extrair app-debug.apk em Downloads e instalar:
"%USERPROFILE%\Downloads\platform-tools\adb.exe" devices
"%USERPROFILE%\Downloads\platform-tools\adb.exe" install -r "%USERPROFILE%\Downloads\app-debug.apk"

Atencao: 200 ms pode permitir um novo clique antes que o MLOG finalize o anterior.
O Enter continua vindo do CMX. Para usar o teclado Bridge, selecione-o no Android.

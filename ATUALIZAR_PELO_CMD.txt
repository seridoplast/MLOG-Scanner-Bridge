MLOG SCANNER BRIDGE v0.7
========================

BAIXAR O ZIP DA V0.7 EM DOWNLOADS. Atualizar GitHub:

cd /d "%USERPROFILE%\Downloads\MLOG-Scanner-Bridge"
powershell -NoProfile -Command "Expand-Archive -LiteralPath (Join-Path $env:USERPROFILE 'Downloads\MLOG_Scanner_Bridge_v7_Monocromatico.zip') -DestinationPath . -Force"
git add -A
git commit -m "MLOG Bridge v7 atividades e interface"
git push origin main

Actions > execucao verde > Artifacts > MLOG-Scanner-Bridge-v7-APK.
Extrair app-debug.apk para Downloads.

INSTALAR PELO CABO USB, com depuracao ativada e computador autorizado:

"%USERPROFILE%\Downloads\platform-tools\adb.exe" devices
"%USERPROFILE%\Downloads\platform-tools\adb.exe" install -r "%USERPROFILE%\Downloads\app-debug.apk"

Opcional, diagnosticar restricao:
"%USERPROFILE%\Downloads\platform-tools\adb.exe" shell appops get br.com.seridoplast.mlogbridge

Se unauthorized: desbloquear o coletor e autorizar computador.
Se falha de assinatura: nao desinstalar sem avaliar backup/configuracoes.

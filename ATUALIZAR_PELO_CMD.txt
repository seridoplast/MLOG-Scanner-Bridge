MLOG Scanner Bridge v0.9 — Atualizacao via CMD

1) Salve MLOG_Scanner_Bridge_v9_Teclado_Enter.zip em Downloads.
2) Abra CMD e execute:

cd /d "%USERPROFILE%\Downloads\MLOG-Scanner-Bridge"
powershell -NoProfile -Command "Expand-Archive -LiteralPath (Join-Path $env:USERPROFILE 'Downloads\MLOG_Scanner_Bridge_v9_Teclado_Enter.zip') -DestinationPath . -Force"
git add -A
git commit -m "MLOG Bridge v9 teclado visivel e enter"
git push origin main

3) GitHub Actions: baixar MLOG-Scanner-Bridge-v9-APK apos Success.
4) Extraia app-debug.apk para Downloads.

INSTALAR PELO ADB:
"%USERPROFILE%\Downloads\platform-tools\adb.exe" devices
"%USERPROFILE%\Downloads\platform-tools\adb.exe" install -r "%USERPROFILE%\Downloads\app-debug.apk"

Esperado: device, depois Success. Se aparecer unauthorized, confirme a depuracao no coletor.

ATENCAO: teclado Gboard visivel, Enter assistido ligado como padrao na v9.
Se o CMX ja emite Enter e duplicar a confirmacao, desative "Confirmar leitura com Enter" nos Ajustes do Bridge.

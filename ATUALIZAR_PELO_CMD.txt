MLOG Scanner Bridge v2.9.1 — COMANDOS NO CMD

1) Salve MLOG_Scanner_Bridge_v291_Bloqueio_585ms.zip em Downloads.

cd /d "%USERPROFILE%\Downloads\MLOG-Scanner-Bridge"
powershell -NoProfile -Command "Expand-Archive -LiteralPath (Join-Path $env:USERPROFILE 'Downloads\MLOG_Scanner_Bridge_v291_Bloqueio_585ms.zip') -DestinationPath . -Force"
git add -A
git commit -m "Bridge v291 bloqueio temporal de 585 ms"
git push origin main

2) GitHub Actions: https://github.com/seridoplast/MLOG-Scanner-Bridge/actions
   Baixe o artefato MLOG-Scanner-Bridge-v291-APK quando a execucao ficar verde.
   Extraia o arquivo app-debug.apk para Downloads.

3) Conecte o coletor e instale:

"%USERPROFILE%\Downloads\platform-tools\adb.exe" devices
"%USERPROFILE%\Downloads\platform-tools\adb.exe" install -r "%USERPROFILE%\Downloads\app-debug.apk"

4) Diagnostico:

"%USERPROFILE%\Downloads\platform-tools\adb.exe" logcat -d -v time -s MLOGBridge:I > "%USERPROFILE%\Downloads\Bridge_v291_Log.txt"

Entrada e Enter: CMX como antes; Bridge so controla foco/toque e injecao de codigo, sem enviar Enter automatico.
Intervalo fixo de clique 585 ms; gatilhos durante o bloqueio nao sao enfileirados.

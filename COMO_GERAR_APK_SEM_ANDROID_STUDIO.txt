COMO INSTALAR v0.2 - SEM ACESSIBILIDADE

Extraia este ZIP e substitua o conteudo do repositorio git local.
Remova dois arquivos antigos de acessibilidade.
Abra o CMD na pasta do repositorio:

del app\src\main\java\br\com\seridoplast\mlogbridge\MlogAccessibilityService.java
del app\src\main\res\xml\accessibility_config.xml
git add -A
git commit -m "v2 sem acessibilidade"
git push origin main

Acesse GitHub Actions e baixe o artifact MLOG-Scanner-Bridge-v2-APK.
Desinstale v0.1 antes de instalar v0.2.
Abra Bridge, habilite e selecione o teclado de leitura, configure o scanner e teste.

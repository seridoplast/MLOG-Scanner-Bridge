Configuração automática

Os coletores procuram este computador por UDP na rede privada. O endereço IP pode mudar; o Bridge tentará redescobrir o painel. É necessário permitir TCP 8765 e UDP 8766 no Firewall do Windows e não isolar os dispositivos Wi-Fi.

Indicadores e limites

Pedidos identificados contam números distintos observados pelo Bridge enquanto conectado. Avisos e observações estão temporariamente suspensos nesta versão; o histórico continua salvo.

“Atividade recente” registra eventos da interface do MLOG; não significa que a pessoa esteja necessariamente bipando naquele instante.

Distribuição local de APKs assinados. O painel não executa comandos shell nem ativa privilégios Android.

Seridóplast · Central de Operações · Dados na rede corporativa local. Não expor TCP/UDP à internet.

Renomear coletor
